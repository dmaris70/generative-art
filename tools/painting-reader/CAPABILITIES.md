# Capability and evidence map

| Component | Packaged use | What it supplies | Current limit |
|---|---|---|---|
| Formal measurement | Connected to `analyze` | Palette, value, edges, cells, formal fields/configurations; input and processing provenance | Reproduction-dependent pixel statistics; fields are not object identities |
| Bounded local image reader | Optional `analyze --vision` | Up to two short observation/interpretation pairs with length/schema/loop checks | May abstain, invent details or miss key relationships; not a thorough reading or verified |
| Source-aware review | Export from existing optional pilot | Attributed proposition-level model assessments and source scope | Caller-provided source; model judgments, incomplete decomposition and same-model compatibility guard are fallible |
| DINO + SAM 2 | Separate tool; `--regions` can import basic records | Prompted masks, overlays and per-mask stats | Incorrect labels/masks and shared model errors; no significance proof |
| Prompt consistency / point targeting | Separate experimental tools | Review flags, optional caller point, candidate selection | A point is human/project assistance; agreement can be jointly wrong |
| Second image model | Separate experimental tool | Model opinion of whether outlined candidate matches a description | False positives and false rejections, especially position and human identity |
| Creative-engine handoff | Connected | Portable JSON, raw evidence and optional directions | Does not generate a painting or dictate the recipient’s style |
| Older studies | Archived scripts and notes | Hypotheses, methods and implementation history | Ancillary scripts may require missing inputs, checkpoints or local environment |

A future comprehensive reading would require better image-grounded subject inventory, spatial/gesture relations, local color accents, multi-scale analysis, cautious interpretation and broader evaluation. The current bridge deliberately reports that coverage gap rather than fabricating details.
